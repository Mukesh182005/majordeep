# paper/

Everything needed to build the IEEE paper from measured results.

| Folder | Contents |
|---|---|
| `config/` | Frozen configurations committed **before** a test set is scored (for example `frozen_image_config.json`, `frozen_audio_config.json`, `audio_calibration.json`). |
| `analysis/` | Scripts that read per-item score files in `paper_results/` and write metrics, tables and figures. They never run a model. |
| `tables/` | LaTeX table snippets generated by `analysis/` scripts. Never edit by hand. |
| `figures/` | Figures generated by `analysis/` scripts. Never edit by hand. |
| `manifests/` | Test-set manifests (relative paths, labels, generator, source, condition, group); added in Phase 4. |
| `latex/` | The paper's LaTeX source; added in Phase 10. |

Rules: `CLAUDE.md` in the repository root. Plan: `docs/paper_upgrade/PLAN.md`.
